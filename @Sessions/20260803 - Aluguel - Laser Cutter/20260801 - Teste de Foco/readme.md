Fizemos uma peça em L com dois retângulos: 20mm x 50mm // 200mm x 50 mm e colamos.

Colocamos ele com a hipotenusa para baixo (na comméia e alinhamos o ponto do laser para encostar no topo.

  | <= Ponteira do laser     == >> == >> 
  V
  /---___
 /       ---___

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~ <= colméia

E depois ligamos o laser numa potência média e mandamos ele andar por toda a placa (para a direita nesse desenho)

Analisando o corte, pode-se notar na altura que o laser cortou mais fino. Essa é a posição perfeito para a lente.

No nosso caso 7 cm. Como a peça foi feita de 1:10 (cada cm andado pra direira foi 1 mm de altura), a distância perfeita é de 7mm.

Como nosso material era de 5mm, a distância para cortá-lo com o foco no centro do material deveria ser distância do foco - largura do material / 2 => (7mm - 5mm/2) = 4,5mm
