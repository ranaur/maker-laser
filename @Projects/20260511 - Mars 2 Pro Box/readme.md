# Caixa para Elegoo Mars 2 Pro

 Tamanha da máquina: 20x20x41,5 (altura)

# Ideias

Fazer uma caixa para devolver a Elegoor Mars 2 Pro pro Vaimberg que sirva como secadora.

A máquina pode ir dentro, protegida com folhas de isopor/foam para guardar, mas serve como curadora, pois dentro é metalizada e tem espaço para o prato giratório e espaço com luz na lateral. Esse espaço lateral é maior para guardar também as resinas e os outros materiais.

A caixa tem que ser forte. Para isso: usar MDF/acrílico de 6mm, Edges H (evitar edge solto)

Talvez fazer um encaixe duplo com trava.

## Pendências

1) Fazer a porta (acrílico 3mm UV + MDF 3/6mm) + puxador e pensar em como travá-la (imã/trinco)

2) Forrar de matalizado e fazer o triângulo para colocar as luzes

3) Definir como será a porta: de dobradiça? De deslixar? Cortando a 5 cm? 3cm? Assim permite que a porta "abra"

4) Fazer um fecho na porta

5) Colocar os suportes entre prateleira e o fundo

6) Colocar os suportes entre o fundo e o chão


### Melhorias para outro corte

Foi cortada a "V5 Universal box with Lid", mas ela contém erros.

1) O travamento das placas deveria ser direito e esquerda e não superior e inferior. isso aconteceu porque a caixa que foi planejada no boxes.py precisou ser "girada" para fazer sem a tampa.
	Toda a caixa precisa ser refeita para que as laterais sejam tipo "h" (com thickness de folga)

2) Refazer a prateleira com:
	 - 6mm a menos no fundo.
	 - um ou dois furos para passar os cabos
	 - com um espaço para colocar um fechamento.
	Fazer um furo para passar a fiação da luz.
	A prateleira interna está com 6mm a mais no fundo.
